Make sure to input values carefully. e.g., if you only want to Long, then you can set the Short values to anything higher than what that stock price could go to, like 9999, and if you only want to Short, you can simply set the Long values to 0.

For the username, you should enter your Windows username, which is the folder name under C:\Users\ where the game’s AppData files are stored.

You can also run multiple instances at once
